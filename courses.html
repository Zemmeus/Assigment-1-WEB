Course catalogue

Six flagship courses across four directions. Every course is project-based: you finish it with something you can actually show to an employer, not just a list of watched videos.

Beginner · 8 weeks

HTML & CSS Foundations

The course this website was built with. You learn document structure first and visual design second.

What you will learn

  • Semantic tags, tables, forms and accessibility basics
  • External stylesheets and all four selector types
  • The box model, flexbox and responsive layouts
  • Publishing a site to GitHub Pages
Intermediate · 10 weeks

JavaScript in Practice

From variables to a working single-page application, written without any framework.

What you will learn

  • Types, functions, arrays and objects
  • DOM manipulation and event handling
  • Asynchronous code, fetch and REST APIs
  • Debugging in Chrome DevTools
Beginner · 9 weeks

Python for Everyone

A first programming language chosen because the syntax stays out of the way while you learn to think in algorithms.

What you will learn

  • Control flow, collections and functions
  • Files, modules and virtual environments
  • Automating boring tasks with scripts
  • An introduction to object-oriented design
Intermediate · 12 weeks

Data Analytics with SQL

Turn a raw database into a dashboard a manager can read in thirty seconds.

What you will learn

  • SELECT, JOIN, GROUP BY and window functions
  • Cleaning messy real-world datasets
  • Charts that do not mislead the reader
  • Presenting findings to a non-technical audience
Beginner · 7 weeks

UX & UI Design Basics

Research, wireframes and design systems — the part of the work that happens before anyone writes code.

What you will learn

  • User interviews and simple usability tests
  • Wireframing and prototyping in Figma
  • Colour, type scales and spacing systems
  • Handing a design over to developers
Advanced · 14 weeks

Mobile Development

Build, test and publish a cross-platform application to a real app store before the course ends.

What you will learn

  • Component-based mobile interfaces
  • Navigation, local storage and device APIs
  • Working with a remote backend
  • Release builds and store requirements

Start with Starter, finish one module and upgrade later — the money you already paid is counted towards the new plan. Write to us through the contact form and a mentor will help you choose.

How to enrol

  1. Pick a course from the catalogue above.
  2. Send the registration form with your preferred study format.
  3. Take a 20-minute online interview with a mentor.
  4. Pay for the first month and receive your group invitation.

Requirements

What you need before the first class

  • A laptop with 8 GB of RAM or more
  • A stable internet connection for live classes
  • An installed code editor such as VS Code
  • Around 8 free hours per week for practice

No previous programming experience is required for the courses marked Beginner
